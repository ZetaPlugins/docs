## Formatting

ServerLinksZ uses a text library called MiniMessage. MiniMessage allows for better formatting and adds text click effects, gradients etc. You can read up on the formatting [here](https://docs.advntr.dev/minimessage/format.html).

## Localization

ServerLinksZ is fully localized. You can change the language of the plugin by changing the `lang` option in the config.yml file.

The language files are located in the `lang` folder. You can add your own language files by creating a new file in the `lang` folder and adding the language code to the `lang` option in the config.yml file. Alternatively you can just modify the existing language files to your liking.

Want to help translate ServerLinksZ into your language? Translations are done on [Twoglot](https://twoglot.com/@KartoffelChipss/serverlinksz). See [Localization](/localization) for how to contribute.
