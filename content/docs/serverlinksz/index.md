Since Minecraft 1.21, servers can show a list of links in the player's pause menu. ServerLinksZ lets you fill that menu with your own links, such as your Discord, website, store or rules, without writing any code.

Each link can also be opened from chat. With `allowCommand` enabled, players can type `/discord` or `/link discord` to get a clickable link.

## Features

- Any number of links in the pause menu, defined in `links.yml` or added in game
- Colored link names with MiniMessage, `&` codes and HEX colors
- Built-in link types such as _Report a Bug_ or _Website_, shown in the player's language
- Chat commands for every link, like `/discord` or `/website`
- Customizable messages in multiple languages
